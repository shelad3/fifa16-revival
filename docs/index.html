EA shut down the FIFA 16 servers in February 2023. This project rebuilds the missing infrastructure — Blaze protocol, FUT web API, squads and the transfer market — as a fully open, community-owned server.

What we're building

A drop-in replacement for EA's online backend, aimed at PC players who still have a copy of FIFA 16.

🌐

Blaze Protocol in progress

Redirector, authentication and session services speaking EA's Blaze/TDF protocol — including the winter15.gosredirector.ea.com HTTP redirector flow discovered in the client binary.

⚽

Ultimate Team API in progress

The full RS4 REST surface from CardsDLLzf.dll: auth, clubs, squads, drafts, seasons, transfer market, packs, TOTW — with the real X-UT-SID header flow.

🗄️

Squads & Database seeded

SQLite-backed player catalog, club management, pack logic and market listings — designed for community-maintained 2026 roster updates.

🔓

No binary patching verified

The client ships with override settings we can use directly: FUT_TARGET_HOSTNAME, FIFA_POW_URL, ONLINE/BLAZEIP and a user.ini override file.

🛡️

Football Club services planned

EASFC "POW" endpoints from powdllzf.dll — entitlements, coins, inventory, catalog, store and friends, via the X-POW-SID session flow.

📡

Online matches planned

UDP relay on port 3659 plus the game's own getPeerAddress HTTP discovery — laying the groundwork for P2P gameplay between community players.

Quick start

Windows 10/11 · Python 3.11+ · a FIFA 16 PC copy

# 1. Clone and set up
git clone https://github.com/shelad3/fifa16-revival.git
cd fifa16-revival
setup.bat

# 2. Start the server
.venv\Scripts\activate
python run_server.py

# 3. (Admin terminal) redirect EA DNS
python recon\setup_dns_redirect.py install

# 4. Launch FIFA 16 — watch logs/network_journal.jsonl
#    for the first real client packets

Key reverse-engineering findings

Extracted from the retail client binaries — full details in the repo docs.

The client can be redirected without patching

  • Real Blaze redirector: winter15.gosredirector.ea.com (plus sdev / stest / scert fallbacks) — HTTP-based, not the bare gosredirector.ea.com everyone assumed.
  • FUT API override: settings FUT_TARGET_HOSTNAME / FUT_TARGET_PORT, or full URLs via FUT_RS4_APIURL_<region>.
  • Football Club override: FIFA_POW_URL plus ONLINE/FORCE-NON-SECURE to skip TLS.
  • Blaze override: ONLINE/BLAZEIP and ONLINE/BLAZEPORT.
  • Settings file: user.ini in the game directory is loaded last with highest priority.
  • Shared infrastructure: fifa15.service.easports.com — Aurora 15 revival knowledge applies directly to FIFA 16.
